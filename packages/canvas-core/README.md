# majom-canvas-core

Reusable canvas engine primitives extracted from `majom-canvas`.

## Install

```bash
npm i majom-canvas-core
```

## Includes

- scene state and selection primitives
- pan/zoom manager
- drag/selection/connection interaction runtimes
- undo/redo and shortcut managers
- connection model/render utilities
- geometry and viewport helpers

## Usage

```ts
import { Scene, PanZoomManager, InteractionRuntime } from 'majom-canvas-core';
```
